# DESIGN.md — AI宝儿 · 五期上手课（终端用户版）

> 风格依据：用户在需求对齐阶段明确选定「青绿自然 · 健康调性」。不命中 academic / consulting / redgold 任一预设分支，走通用设计原则 + 用户显式风格指令。

## 1. 画布与母版（1280 × 720）

| 母版区 | 垂直位置 | 具体 px | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 20px → 120px | 高 100px | 主标题 36px bold `#1E3A32`；标题下方 6px 处一条 56×4 圆角色条 `#1F7A5C`（全篇位置一致） |
| **B · 内容区** | 128px → 656px | 高 528px | 一切正文、图形、卡片；禁止挤占 A/C 区 |
| **C · 页脚条** | 660px → 700px | 高 40px | 左侧「AI宝儿 · 五期上手课」14px `#6B7C75`；右侧页码 `NN / 33` 14px `#6B7C75` |
| 页面 padding | 上 20 / 下 20 / 左 72 / 右 72 | — | 内容区宽度 = 1280 − 144 = **1136px** |

- Slide 高度固定 720px，**任何页不得溢出**：`20 + 100(A) + 8(gap) + ≤528(B) + 4(gap) + 40(C) + 20 = ≤720`
- 封面（01）、章节扉页（03/09/16/21/27）、结业页（33）**省略 C 区页码**，采用自定义版式；其余 27 页严格保持三区母版。

### 2.1 每页色彩分配

| 页类型 | 主色 | 辅色 | 强调色 |
| :--- | :--- | :--- | :--- |
| 常规 supporting 页 | 45–55%（多为背景与标题条） | 20–30% | ≤ 5% |
| Hero 页（01/06/12/14/18/24/30/33） | 45–55% | 20–25% | **15–20%** |
| 章节扉页（03/09/16/21/27） | 60%（大色块铺底） | 25% | 5% |

至少 8 页（全部 Hero）与其他页色彩比例差异 > 10% ✓

### 2.2 渐变与半透明

- 封面 / 结业页底：`linear-gradient(135deg, #F2F8F4 0%, #DCEDE3 100%)`
- 章节扉页大字块：`linear-gradient(135deg, #1F7A5C 0%, #2E9B77 100%)`
- 强调数字卡片：`linear-gradient(135deg, #1F7A5C 0%, #2E9B77 100%)`，白字
- 图形次级填充：`rgba(168,213,186,0.45)`
- 背景装饰（有机曲线 / 光晕）：`opacity: 0.12 – 0.28`
- 卡片阴影：`0 4px 20px rgba(30,58,50,0.08)`
- **禁止**：全幅高饱和撞色铺底；同一页出现两套主色板。

## 4. 信息密度门禁

| 页面类型 | 正文字数下限 | 主视觉占 B 区 |
| :--- | :--- | :--- |
| 封面（01） | 40 | ≥ 45% |
| 目录（02） | 200 | — |
| 章节扉页 | 35 | ≥ 45% |
| 内容页 · 单主题 | **200** | ≥ 30% |
| 内容页 · 卡片组 | 每卡 ≥ 100（合计 ≥ 300） | — |
| Hero 内容页 | 190 | ≥ 40%（或 ≥ 48px 锚点数字） |
| 结业页 | 50 | ≥ 40% |

- **留白上限**：常规内容页 ≤ 26%；Hero 页 ≤ 36%；封面 / 扉页 / 结业不受限。
- **容器填充率 ≥ 85%**：卡片内文字 + 图形垂直占用 ≥ 容器高 85%；卡片尾部标签条用 `marginTop: 'auto'` 钉底。
- **横向兄弟卡对齐**：同行卡片的标题块 / 正文块 / 尾部条在 y 轴等高对齐。
- **焦点留白**：巨型数字四周 ≥ 40px 呼吸空间。

## 5. 配图系统（全 SVG 方案）

**策略声明**：用户在生产阶段选择不调用生图，全篇主视觉采用**内联 SVG 结构化图形**（流程、矩阵、六边形、时间轴、状态机、巨型数字、有机曲线背景）。本篇无位图，因此不存在摄影 / 插画 / 3D 混用问题。

**SVG 统一视觉语言**（全篇必须一致）：

| 元素 | 规格 |
| :--- | :--- |
| 节点 | 圆角矩形 `rx=12`，主节点填充 `#1F7A5C` + 白字；次节点填充 `rgba(168,213,186,0.45)` + `#1E3A32` 字 |
| 连线 | `#A8D5BA`，`strokeWidth=3`，箭头端点用实心三角 |
| 焦点节点 | 填充 `#E08A3C` + 白字（每图 ≤ 1 个） |
| 背景装饰 | 有机曲线 / 光晕，`opacity 0.12–0.28`，色取 `#1F7A5C` 或 `#A8D5BA` |
| 圆点标记 | r=5，主色实心，用于列表项引导 |
