# 每日闯关：内部产品沟通训练

第一版将客户陪练改为固定题库的选择题游戏，普通 AI 问答照常使用。无需配置额外 Coze Bot，也不产生陪练模型调用。

## 使用与内容管理

- 首页“今日闯关”：每天推荐一关，10道单选情景题。选择后展示推荐答案、具体解析和“下一句可以这样说”。
- 题库共100题，益生菌、营养补充、蛋白质、灌肠各25题，交错组成10关；每关覆盖四类内容。
- 自由练习可选任一完整关卡。个人记录可恢复未完成练习，或查看已完成局的全部答案与解析。
- 后台“每日闯关”可编辑场景、四个选项、推荐答案、解析、参考回复和启用状态。每关保持10道启用题才能用于新练习。
- 初始内容以需求沟通、产品资料理解、常见异议与服务跟进为主。需要训练自家具体产品时，直接把品牌资料和标准解释写入对应题目即可。
- 当天每日题在第一次读取时固定。后台修改用于后续新练习；当天已固定的每日题及已开始会话保留题目快照。
- 参考资料在后台相关题目内可查阅；通用知识来源映射位于 `services/practice_bank.py`。

## 积分与荣誉

- 每日局每答对1题得10分，答完10题一次性入账，每人每天最多100分。
- 同一身份当天只有一局计分的每日闯关；再次进入恢复原局或显示原成绩。第一次提交的选项锁定。重复请求与刷新不重复加分。
- 自由练习保存答题成绩与解析，不计周榜积分，包括重练当天关卡。
- 所有日期与周界限按北京时间。跨日完成旧每日局时保留成绩，不补发旧日积分，可另开当天每日局。
- 本团队周榜按周一至周日汇总；仅有正积分的成员上榜，同分并列，采用竞赛排名（如1、1、3）。展示前100名及边界并列者，同时单独返回本人名次。
- 本周荣誉由上周最终团队排名决定：第1名“周冠军”、第2–3名“沟通达人”、第4–10名“学习之星”。同排名同头衔，每周自动重算，无需定时任务。
- 使用现有浏览器身份，不按姓名合并。更换设备或重新生成身份可能形成独立记录，同名成员也可能出现多条榜单记录。会话开始时固定积分所属团队。

## 启用

1. 启动应用，迁移 `202610140002` 自动创建独立 `practice_quiz_*` 表并写入100题。
2. 后台“每日闯关”查看、调整题库。
3. 后台“功能开关”开启“每日闯关”。默认关闭，也可使用 `PRACTICE_ENABLED=true` 作为默认值（数据库设置优先）。
4. 开启检查要求至少有一组完整10题。功能关闭时后台管理可用，前台入口隐藏且 API 拒绝访问。

迁移不会改写普通聊天、产品资料或旧版陪练表。重复执行迁移不会覆盖已编辑的题库。

## 接口与数据

用户接口以 `/api/practice` 为前缀，沿用 `identity_required`：

| 接口 | 用途 |
| --- | --- |
| GET `/catalog` | 关卡、每日推荐、本人当天进度；记录访问 |
| GET `/daily` | 固定当天推荐（不返回答案） |
| POST `/sessions` | `request_id`、`mode: daily/free`，自由练习附 `batch_no` |
| GET `/sessions?page=1` | 本人记录，每页20局 |
| GET `/sessions/<id>` | 恢复本人答题状态 |
| POST `/sessions/<id>/answer` | `request_id`、`question_id`、`option_index`（0–3） |
| POST `/sessions/<id>/next` | `request_id`、当前已答 `question_id`；重复推进不跳题 |
| GET `/scores` | 今日与本周积分、团队榜单、本人名次和本周荣誉 |

管理接口沿用 `admin_required`：GET `/api/admin/practice` 返回题库和团队汇总，PUT `/api/admin/practice/questions/<id>` 编辑题目。

题目及选项顺序快照保存在服务端。未答题目只返回当前题，不返回推荐答案和解析。已答题可返回反馈，结束后可回看全局。身份与团队来自服务端认证；客户端传入的分数、用户名和团队不会参与结算。

SQLite `BEGIN IMMEDIATE` 串行处理写入；每日会话、单题答案、答案请求标识和每日积分均有唯一约束。最后一题与积分在同一事务内提交。网络中断后可以读取会话恢复，失败事务不丢失已有答案。

后台提供累计访问人数、参与人数、开始局数、完成局数、开始率、完成率、次日回访人数、后续七日再次练习人数。以不同浏览器身份计数，次日回访按开始练习后第二天访问闯关统计，七日再练按开始日期统计。记录与解析只通过本人接口提供，后台只展示团队汇总。

试用两周，结合这些数据调整场景难度与解析。手机与微信实机验收：进入每日局、选项触控、解析阅读、刷新继续、完成结算、回看记录、团队周榜。自动化和桌面移动视口检查不能替代微信实机验收。

## 后续题库维护

后台使用列表与编辑区并排布局，提供关键词搜索、分类／关卡／启用状态筛选与分页。编辑期间切换筛选不会清空右侧表单；可展开学员预览核对呈现内容。团队统计收在下方折叠区。

### 少量调整

直接打开题目修改。新增相似场景用“复制新增”，替换客户描述、选项和解释即可。复制出的题目默认停用并放入新的关卡，原题保留。题库数量不再固定100道，关卡也可继续增加。每关有10道启用题目时自动可练。

### 批量维护

1. 新增：下载CSV模板，用Excel或WPS填写，每行一道题；id和版本留空。
2. 修改：导出当前题库，保留题目id和版本，只修改需要调整的行；可删除文件中不需导入的行，系统不会因此删除题库中的题目。
3. 按10题一组填写关卡号。推荐答案使用A/B/C/D；启用填1，停用填0；保存为UTF-8 CSV。
4. 上传文件后先检查新增／更新数量、前10道题预览与逐行错误，再点击写入。整批验证通过才一次提交。
5. 已更新的题目不能被旧文件覆盖；重新导出该题再修改。网络重试同一请求不会重复新增。

后台接口新增：POST `/questions`（新增，携带request_id）、GET `/export`、POST `/import/preview` 和 POST `/import`（csv文本和request_id）。接口路径均以 `/api/admin/practice` 为前缀。迁移 `202610140003` 记录后台写入请求以支持重试。

### 内容扩充节奏

建议团队共用一份主表，每周从真实提问、伙伴容易选错的场景和新产品资料中整理10–20道题。统一填写客户原话、四种处理方式、推荐答案、解析和参考回复，先以停用状态导入，负责人完善后按整关启用。

后续适合增加产品名称与场景标签，以及按题统计错误率，帮助定位最需要补充的内容。当前版本已实现新增、复制、搜索筛选和CSV批量维护；产品标签、错误率分析及AI辅助起草仍属后续方案。

## 阶段题库

后台“阶段题库”可创建主题（名称、简介、开始／结束日期）、独立维护题目并开启／关闭。一个主题可上传50道题分成5关，也可继续扩充。阶段分类支持自定义文字，如“三伏天”“夏季客户沟通”。

操作：创建阶段 → 选择该题库 → 下载模板／上传CSV → 每关安排10道启用题 → 设置开放日期并开启。新增题默认停用，批量发布时在CSV“启用”列填1。日期按北京时间，包含开始和结束当天；未到开始日和结束日之后，前台自动以常规每日闯关为主。启用另一个主题会停用此前主推主题。

开放期间：首页阶段卡片占主要位置，普通每日闯关缩为小入口；练习页阶段专题置顶，普通每日题保留为小卡，常规自由练习收在折叠区。首页在回到页面和每分钟重新检查开放状态。

阶段每日专题与普通每日闯关共用每天唯一一局计分，每答对1题得10分、每天最多100分。已经选择其中一局后，另一入口改为自由练习；阶段其他关卡均可自由练习。团队周榜和荣誉共用同一积分体系。

批量导入阶段题时可勾选“替换整个阶段题库”。系统先验证整份文件，再归档旧题、写入新题，失败不改变题库；旧练习、答案、积分和题目快照保留。当天已固定的专题每日题仍使用原版本，自由练习立即使用新题。阶段关闭／结束后不再创建新练习，已开始的练习可从个人记录恢复。

迁移 `202610140004` 添加阶段元数据、题目归属、归档标记、会话主题快照及每日专题快照。管理接口 GET `/api/admin/practice?stage_id=ID` 维护指定题库；新增、导出、预览及导入接口同样使用stage_id查询参数。POST `/stages` 创建阶段，PUT `/stages/<id>` 编辑。POST `/import` 的 `replace:true` 仅适用于阶段题库。

公开接口 GET `/api/practice/promotion` 仅返回当前开放主题简介；题库与答案仍通过用户认证接口访问。创建练习时传 `stage_id` 选择阶段题（0表示常规），题目与团队信息由服务端确定。

## 客户问题入口与每周主题

首页主卡片显示一句客户问题，点击直接进入该题的四个选项；答完首题可继续剩余9题，也可保存退出。首页“继续今天的练习”恢复实际进度；每日计分局完成后入口改为自由练习。积分仍为每天一局、最高100分。

后台创建阶段时新增“每周主题”类型，默认下一个周一开始、连续7天（可调整开始日，结束日自动计算）。已有阶段保持“阶段专题”。每周主题先准备，在开始日或开放期间由负责人开启；到期自动收起。

每周操作：

1. 选择当前每周主题，点击“录入本期新题”或“新题CSV导入”。5–10道新题进入母题库，并自动勾到本期；母库常规关卡未满10题也能用于主题。
2. 在组题区搜索、按分类筛选、批量勾选旧题，补足30题。可查看已选题、移出题目或标记“本期新题”。录入新题前会保存已有选择。
3. 预览七天安排与群文案，点击“生成30题主题包”。系统将新题均匀分布到3组，旧题补齐每组10题。发布不等于开启。
4. 在阶段设置中开启。周一至周三初练三组，周四至周六复练三组，周日精选复练第一组；七天入口题不同，新题优先作为入口。
5. 点击“推广预览”，复制任一天的群文案。链接指向 `/?practice_theme=ID`，进入当前可练内容；过期主题提示已结束，并展示当前主题或常规题。文案由负责人自行转发。

母题库修改用于下期；本期副本可单独修改文本、选项与解析，关卡分组保持固定。当天首次读取后的题目快照不随修改变化。每周主题整库重组使用“生成30题主题包”；导出CSV按id更新可修正本期副本。所有发布与新题导入支持同一请求重试，不重复新增。

新增认证接口：GET `/api/practice/entry` 返回入口问题及本人进度，不返回答案；POST `/api/practice/entry/impression` 记录实际可见的卡片。创建会话携带 `entry:true` 使用当天固定快照，或恢复既有会话；`entry_day`、`entry_stage_id`、`entry_question_id`用于检查页面展示是否已过期。刷新后的入口创建请求仍可用原标识重试。

管理接口：GET `/api/admin/practice/stages/<id>/weekly` 获取选题工作台；PUT `/weekly/selections` 保存选择；POST `/weekly/publish` 生成题包（request_id）；GET `/api/admin/practice/stages/<id>/promotion` 获取每日推广预览。新题CSV预览和写入沿用原导入接口，携带 `weekly_new_import:true`，当前题库须为每周主题。

迁移 `202610140005` 添加主题类型、源题归属、选题草稿、七天安排、会话入口标记、入口请求映射和统计事件。后台按主题展示实际入口展示人数、点击人数、首题作答人数和整局完成人数，以及点击率和首题完成率。统计以独立浏览器身份计数；刷新、重复提交和重新练习不重复增加同一身份的主题人数。其他团队学习概况仍沿用已有统计。

试用两周：每周新增5–10题、复用20–25题，由负责人固定节奏转发；比较入口点击率、首题完成率、整局完成率与回访，并收集哪些题最像真实客户问题。微信实机重点检查入口链接、触控选项、复制群文案和恢复进度。


## 轻量客户接待挑战

答题界面使用客户消息气泡、回复卡片和紧凑接待进度条。所有内容复用现有题目，不新增后台字段、数据库表或接口。进度、当前连对和最长连对从服务端作答记录推导，保存或刷新后可恢复；只有本次提交成功（包括读取恢复成功）时播放短暂点亮动画，重新打开记录不播放。第3、6位客户完成时有进度鼓励，连续答对3题起展示连对数量。

完成后展示接待战报、准确数量、最长连对和实际入账积分：10题全对为“接待达人”，7–9题为“沟通能手”，0–6题为“练习完成”。徽章仅属本局展示，不额外计分或更改周榜荣誉。复盘优先列出错题，参考回复支持复制；再挑战沿用自由练习。自由练习首题提示不承诺积分结算。手机和微信实机验收增加长消息/回复、大字号、复制成功及失败提示。
