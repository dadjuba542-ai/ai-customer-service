# AI宝儿智能体

AI 智能对话系统，基于 Coze Bot API。

## 项目速查

为了方便后续快速接手项目，已补充项目概览文档：

- [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md)
- [HANDOFF.md](./HANDOFF.md)：启动、部署、管理员、发布和故障排查说明

## 功能

- AI 智能对话（四种咨询类型）
- 快捷功能入口
- 客户案例档案推荐（按症状/产品标签匹配，回答后展示相关案例）
- 图文资讯推送（管理后台发布，支持 HTML 图文混排）
- 管理员后台：资讯管理、智能体配置、Coze API Key 在线更新
- 语音输入：腾讯云实时 ASR 边说边出字，异常时自动用同一段录音批量转写；长期密钥仅在后台加密保存
- AI 转人工营养咨询：明确意图触发、在线排队、超时留言、PC 营养师工作台、咨询档案与 CSV 导出

## 1.1.4 版本更新说明

- 新增 AI 优先的人工兜底流程：仅在“深度调理答疑”中识别明确转人工意图，先推荐专用营养咨询 AI，再由用户决定是否联系真人。
- 新增独立 PC 营养师工作台 `/consultant`，支持坐席登录、上下线、多会话接待、排队、未读提醒、声音与桌面通知。
- 营养咨询 AI 可通过 `handoff_ai_agent_id` 独立配置，不跟随首页当前智能体。
- 在线等待默认 120 秒；未获真人回复时自动转为异步留言并恢复 AI，营养师稍后回复后前台单独展示留言结果。
- 新增咨询档案、关键词/日期/团队/服务方式筛选、只读详情和同一用户历史回复。
- 新增单次、多选、按筛选条件导出 CSV，包含 5,000 条上限、Excel 中文兼容、公式注入防护和导出审计；导出不包含转人工前 AI 对话。
- 修复人工咨询轮询导致的聊天区域闪烁、结束后未自动切回 AI、转接前有效问题未传入客服台等问题。

## 1.1.3 版本更新说明

- 语音方案统一为腾讯云，默认实时识别，支持边说边出字。
- 实时链路异常时复用同一段本地录音走腾讯云批量转写，无需用户重新录音。
- 新增连接中、录音时长、音量、识别收尾、取消等反馈；识别文字只进入输入框，不自动发送。
- 腾讯云长期密钥仅保存在服务端，前端只获取短时单次签名地址。
- 每位用户独立创建实时语音会话和 `voice_id`，多人同时使用不会串音或共享录音状态。

## 1.1.2 版本更新说明

- 首页新增可轮播的“精选资讯”条，内容与发现页资讯、首页最新资讯相互隔离，避免重复展示。
- 后台新增首页滚动内容管理，普通资讯列表不再混入首页滚动内容。

- 后台新增客户需求记录查看入口，保持轻量记录，不引入复杂跟进流程。
- 修复图标字体不可用时的显示问题，首页和后台改用稳定的几何图标 fallback。
- 管理员账号继续使用数据库哈希密码，不在代码和 Git 中写入默认密码。

## 安全启动

- `SECRET_KEY` 必须设置为至少 32 个字符的随机值；未设置时应用拒绝启动。
- 默认关闭公开注册。首次创建管理员请在部署环境执行：

  ```bash
  python3 scripts/create_admin.py admin
  ```

- 重置现有管理员密码请执行 `python3 scripts/reset_admin_password.py admin8`，密码只在终端交互输入，不会进入 Git。

- 生产环境应将 `DATABASE_DIR` 和 `UPLOAD_DIR` 指向持久化磁盘（Railway 默认是 `/data` 和 `/data/uploads`）。
- 若此前使用过旧版本，请立即轮换 Coze/腾讯云凭据；旧数据库备份不得提交到 Git。
